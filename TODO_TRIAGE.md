# TODO triage

Every open item is either committed with an owner and a date, or deleted. An open TODO list in a
client-facing repository is a scope confession.

| Item | Decision | Owner | Date | Note |
|---|---|---|---|---|
| (each TODO.md entry) | Commit or Delete | | | |

Rule: items untouched for sixty days are deleted with a commit message naming them, so the decision
is visible rather than silent. This file is removed once the table is empty.
